A manufacturing system is arranged as a serial production line with 4 machines connected in series: M1 -> M2 -> M3 -> M4.

A source feeds the line and a sink collects finished parts. Every buffer has the specified capacity.

Per-station measured facts (obtained from a monitoring period of the real plant):

MachineName  Avg_Time_per_part_s  Availability_%  MTTR_s  EnergyIdling  EnergyWorking
         M1                59.99           99.99   46.14          0.30           3.00
         M2                80.28          100.00    1.00          0.45           4.98
         M3                70.16           99.88  272.07          0.42           4.49
         M4                75.03          100.00    1.00          0.34           4.00

Buffer list with their capacity:
B0(Capacity = 25), B1(Capacity = 10), B2(Capacity = 10), B3(Capacity = 10)

New parts arrive at the line at a constant rate: one part every 45 seconds.

Simulation requirements:
- Time is measured in seconds throughout the model.
- Use a single source, the 4 machines in series (each with the measured average processing time and measured availability/failure behaviour), and a single sink.
- The model must create its own simpy.Environment, build the structure, validate it, and run the simulation for at least 432000 seconds (about 5 days) in one go at module level.
- Only structure and the run code; no extra commentary.
